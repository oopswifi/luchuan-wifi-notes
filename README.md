# 陆川的修网线笔记

大家好，我叫陆川，二十七岁，程序员。人生信条是：代码能跑，就别碰它。

上周五下午五点五十九分，距离下班还有一分钟，我被"优化"了。纸箱里装着一盆半死的绿萝、一个印着"年度最佳员工"的马克杯，和我所剩无几的尊严。

后来大学室友老周打来电话：日结三千，包吃包住，海边别墅。一档恋爱综艺缺一个技术，负责网络和监控设备，今晚就得到。

我对人类没有兴趣，我只对 Wi-Fi 信号有兴趣。
